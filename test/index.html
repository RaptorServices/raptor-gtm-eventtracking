Setup

Enter the ID of a GTM container with the Raptor tags. Use GTM Preview with http://localhost:8080/ to test unpublished changes.

      Triggers (Custom Event)

      One trigger per event name: consent_granted, view_item, add_to_cart, remove_from_cart, clear_cart, view_cart, purchase, select_item, search, search_click, login. The page pushes consent_granted on every page load once cookies have been accepted.
